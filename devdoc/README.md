- `graph_compiler_alignment_plan.md` — 图编译器对齐计划
- `global_config_feedback.md` — 全局配置链路反馈记录
- `third_party_dependency_map.md` — 第三方依赖映射
- `whitepaper-build.md` — 白皮书 LaTeX 编译本机备忘
